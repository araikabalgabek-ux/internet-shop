# Интернет дүкен жүйесі

## Жоба туралы

Бұл жоба интернет дүкен жүйесін модельдеуге арналған.

Жүйе арқылы пайдаланушы тауарларды қарап, таңдап,
себетке қосып және тапсырыс бере алады.

## Негізгі мүмкіндіктер

- Пайдаланушыны тіркеу және авторизациялау
- Тауарларды қарау
- Тауарды себетке қосу
- Тапсырыс беру
- Төлем жасау
- Тапсырысты бақылау
- Әкімші арқылы тауарларды басқару

## Жоба мақсаты

Интернет дүкеннің негізгі функционалдық мүмкіндіктерін
жобалау және ақпараттық жүйенің құрылымын ұйымдастыру.
